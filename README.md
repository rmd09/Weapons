# О приложении
Это приложение я писал для тренировки ООП, и особого практического применения оно не имеет. Простыми словами, это небольшой каталог оружия с описанием и жалким подобием интерактива (для взаимодействия с оружием открывается новая форма с активными кнопками).
# Использование
Чтобы запустить приложение, тебе понадобится [Visual Studio](https://visualstudio.microsoft.com/ru/vs/community/). Просто скачай архив кода, распакуй в любую папку и открой файл решения ```Weapon.sln``` с помощью Visual Studio. Далее запусти приложение.
