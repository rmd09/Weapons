# О приложении
Это приложение я писал для тренировки ООП, и особого практического применения оно не имеет. Простыми словами, это небольшой каталог оружия с описанием и жалким подобием интерактива (для взаимодействия с оружием открывается новая форма с активными кнопками).
# Варианты запуска
## Скомпилировать проект в Visual Studio
Чтобы запустить приложение, тебе понадобится [Visual Studio](https://visualstudio.microsoft.com/ru/vs/community/). Просто скачай архив кода, распакуй в любую папку и открой файл решения ```Weapon.sln```. Далее кликните ПКМ по решению проекта и поставьте в качестве исполняемого проекта ```Program```. Соберите решение (*Сборка >> Собрать решение*) и запустите приложение.
Однако могут возникнуть ошибки:
### MSB3821
```MSB3821: не удалось обработать файл <какой-то файл>, так как он находится в Интернете или ограниченной зоне либо имеет веб-метку```
Скорее всего это будут файлы [Weapons-main\Interactive\Form1.resx](https://github.com/rmd09/Weapons/blob/main/Interactive/Form1.resx) и [Weapons-main/Program/Form1.resx](https://github.com/rmd09/Weapons/blob/main/Program/Form1.resx). Подробно о том, почему происходит такая ошибка, [тут](https://learn.microsoft.com/ru-ru/visualstudio/msbuild/errors/msb3821). Там же будет инструкция о том, как это исправить. 
Но если кратко, то нужно в проводнике перейти в свойства файла и поставить галочку рядом с пунктом *"Разблокировать"* в самом низу и нажать *"Применить"*.
